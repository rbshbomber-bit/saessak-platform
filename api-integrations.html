키가 없어도 새싹매치는 동작합니다. 다만 해당 API 기반의 시장근거·상권·특허·통계 보강은 "확인 필요"로 남깁니다.

형님이 직접 해야 할 일

  1. 각 기관 사이트에서 API 활용신청을 하고 키를 발급받기
  2. Vercel 프로젝트 Settings → Environment Variables에 키 추가
  3. Production, Preview, Development를 체크하고 저장
  4. Deployments에서 최신 배포를 Redeploy
  5. 이 페이지를 새로고침해서 상태가 "연동 가능"으로 바뀌었는지 확인
